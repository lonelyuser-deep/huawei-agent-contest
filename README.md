# 智云校遇

> 校园快递管理 + 校园论坛一体化 Web 应用

智云校遇是一个面向校园场景的 Web 应用，帮助大学生高效管理快递取件，同时提供校园论坛交流平台。采用 Vue 3 + Vite + TypeScript 构建，数据存储在浏览器本地（localStorage），无需后端服务即可运行。

## 功能概览

### 快递服务

| 功能 | 说明 |
|------|------|
| 快递看板 | 查看待取/已取快递列表，支持快捷取件、统计概览 |
| 添加快递 | 手动录入快递信息（驿站、取件码、快递公司、电话） |
| 短信智能解析 | 粘贴取件短信，自动识别驿站、快递公司、取件码、电话 |
| 取件提醒 | 设置提醒，避免遗漏取件 |
| 快递详情 | 查看单条快递完整信息，支持标记已取/删除 |

### 校园论坛

| 功能 | 说明 |
|------|------|
| 论坛首页 | 浏览全部帖子，按分类筛选，查看统计卡片 |
| 发布帖子 | 选择分类、填写标题/内容/标签，表单校验 |
| 帖子详情 | 查看帖子内容、浏览量、点赞、评论 |
| 分类体系 | 7 个分类：学习交流、校园生活、二手交易、活动社团、失物招领、求助问答、表白交友 |

### 系统功能

- 封面动画引导页
- 侧边栏导航（分区显示：快递服务 / 校园论坛 / 系统）
- 移动端底部导航栏（响应式适配）
- 应用设置页

## 技术栈

- **框架**：Vue 3.4（Composition API + `<script setup>`）
- **构建工具**：Vite 8.3
- **语言**：TypeScript 5.4
- **路由**：Vue Router 4.3
- **数据存储**：localStorage（零后端依赖）
- **样式**：原生 CSS 变量主题系统（自然校园配色）

## 快速开始

### 环境要求

- Node.js >= 18（推荐 v24.x）
- npm >= 10

### 安装与运行

```bash
cd web
npm install --legacy-peer-deps
npm run dev
```

启动后访问 http://localhost:5173/

### 构建生产版本

```bash
cd web
npm run build
```

构建产物输出到 `web/dist/`。

## 短信解析示例

将取件通知短信粘贴到"添加快递"页面的解析框中，系统会自动提取信息：

```
【菜鸟驿站】您的顺丰快递已到达菜鸟驿站，取件码 1-2-3045，
凭码取件，联系电话13800138000，地址：XX大学南门。
```

解析结果：

| 字段 | 提取值 |
|------|--------|
| 驿站 | 菜鸟驿站 |
| 快递公司 | 顺丰 |
| 取件码 | 1-2-3045 |
| 电话 | 13800138000 |

支持的快递公司：顺丰、圆通、中通、申通、韵达、百世、EMS、京东、德邦、极兔等。
支持的驿站类型：菜鸟驿站、丰巢快递柜、智能快递柜、京东快递柜、邮局等。
