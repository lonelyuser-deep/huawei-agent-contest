# 校园快递助手 📦

> 华为 agent 参赛项目 — 面向校园生活服务的微信小程序 Demo

## 项目简介

帮助大学生解决取快递时多个取件码混乱、难以清晰判断哪些快递还未取件的痛点。支持智能识别快递通知、统一管理取件码、一目了然的待取/已取看板。

## 功能特性

### ✅ 已实现（Demo v1.0）

- **快递看板**：待取件 / 已取件分类展示，顶部统计一目了然
- **智能录入**：粘贴快递通知文字，自动识别驿站、取件码、快递公司、手机尾号
- **手动填写**：表单方式添加快递信息
- **一键取件**：列表上直接标记已取，快捷操作
- **详情管理**：查看详情、取消取件标记、删除记录
- **本地存储**：数据保存在小程序本地，无需后端

### 🔜 规划中

- 拍照 OCR 识别快递短信截图
- 接入 AI Agent 实现多轮对话（自然语言交互）
- 智能提醒（还有 X 个快递未取）
- 扩展模块：食堂导航、学习助手、校园出行等

## 技术栈

- 微信小程序原生开发（WXML + WXSS + JS）
- 本地存储（wx.setStorageSync）
- 规则引擎解析自然语言（utils/parse.js）

## 项目结构

```
├── app.js                    # 小程序入口
├── app.json                  # 全局配置
├── app.wxss                  # 全局样式
├── project.config.json       # 项目配置
├── sitemap.json              # 搜索配置
├── pages/
│   ├── index/                # 首页 - 快递看板
│   ├── add/                  # 添加页 - 智能录入 + 手动表单
│   └── detail/               # 详情页 - 查看/标记/删除
└── utils/
    ├── storage.js            # 本地存储工具
    └── parse.js              # 自然语言解析工具
```

## 使用方法

1. 下载 [微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)
2. 导入本项目目录
3. 编译预览，扫码即可在手机上体验

## 开发说明

- Demo 阶段使用 `touristappid`，无需注册即可本地调试
- 数据存储在小程序本地，清除小程序缓存会丢失数据
- 后续接入 AI Agent 时，在 `utils/` 下新增 `agent.js` 调用模型 API
